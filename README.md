# React Static Site Practice

A static website foundation created with React, TypeScript, and Vite.

## Prerequisites

- Node.js 24
- npm

## Install dependencies

```bash
npm install
```

## Start local development

```bash
npm run dev
```

## Run quality checks

```bash
npm run lint
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Available scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the local development server |
| `npm run lint` | Run Oxlint |
| `npm run build` | Run TypeScript checks and create the production build |
| `npm run preview` | Preview the production build locally |

## Current status

Project foundation only. Website implementation will continue in separate feature branches.
